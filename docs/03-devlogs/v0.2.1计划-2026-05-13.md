## 新增功能

### 1. 题型筛选切换

在主工具栏增加"题型："下拉（全部题型 / 完形填空 / 阅读理解 A+B / 翻译题），切换后词频基于当前题型重新计算。

- **后端**：`section_filter` 字段 + `SECTION_FILTER_MAP` + `_index_cache` 四份索引缓存
- **前端**：`App.tsx` 题型 select + 切换时关弹窗/刷新生词本
- **导出**：文件名加题型前缀 `words_reading_high.xlsx`
- **设计文档**：`docs/02-design/题型筛选功能设计方案-2026-05-13.md`

### 2. 完形填空选项词统计

完形填空的 A/B/C/D 选项词在数据预处理时被清洗掉。现在从 44 个原始 DOCX/PDF 中恢复选项词，仅在切换到"完形填空"题型时注入词频统计。

- **提取脚本**：`scripts/extract_cloze_options.py`（24 个文件，1,789 个选项词）
- **后端**：`option_words` 字段 + `_build_index()` 中 cloze 时注入
- **效果**：完形填空 1,584 词 → 2,032 词（+448 词）
- **设计文档**：`docs/02-design/完形填空选项词统计设计方案-2026-05-13.md`

### 3. 墨墨未覆盖词汇检索与翻译

检索出 1,975 个在墨墨词库中不存在但在考研真题中出现的实词，用 DeepSeek 批量翻译。

- **检索**：`scripts/find_uncovered_words.py`（API 分页 + 本地词库对比）
- **清洗**：`scripts/deep_clean_uncovered.py`（黑名单 + 系统词典）
- **翻译**：`scripts/translate_uncovered_words.py`（66 批 × 30 词，零失败）
- **产出**：`data/exports/uncovered_words_translated.json`（1,975 词释义）
- **设计文档**：`docs/02-design/墨墨未覆盖词汇检索翻译设计方案-2026-05-13.md`

## 关键新增状态变量

| 变量 | 含义 |
|------|------|
| `_session_settings["section_filter"]` | 题型筛选 `"all"|"cloze"|"reading"|"translation"` |
| `SECTION_FILTER_MAP` | Section key 映射 |
| `_index_cache` | 按 `(section_filter, exclude_levels, exclude_groups, papers)` 缓存的索引 |
| `paper["option_words"]` | 完形填空的选项词列表（仅加载，不注入） |

## 已知新增问题

| 问题 | 严重程度 | 说明 |
|------|:---:|------|
| 完形选项提取覆盖率 | 低 | 24/44 文件成功，老 .doc 和异常格式 DOCX 未覆盖 |

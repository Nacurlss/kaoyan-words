# v4 运行检查与筛词污染修复记录

## 背景

本轮目标是实际运行项目并检查筛词结果，而不是只看代码。用户指出三个核心问题：

1. 筛词把试卷共有说明部分算进去了，例如 `Directions`、`ANSWER SHEET`。
2. 筛词不应包含选择题选项、题干等非文章内容。
3. 释义字段里混进了例句，释义应该只包含词性和中文意思。

此外，还检查了 `start.sh` 是否能正常启动项目。

## 实际运行与导出检查

### 后端依赖与 Python 版本

项目代码使用了 Python 3.10+ 类型语法，例如 `str | None`。本机默认 `python3` 是 3.9，会直接报错：

```text
TypeError: unsupported operand type(s) for |: 'type' and 'NoneType'
```

本机可用的 `python3.11` 能正常运行项目，因此后续检查使用 `python3.11`。

### 原始导出问题

启动后端并导出当前结果：

- `export_all_current.csv`
- `export_high_current.xlsx`

抽查发现：

| 问题 | 例子 |
|------|------|
| 说明部分进入词频 | `sheet` 频率 `0.7207`，大量来自 `ANSWER SHEET` |
| 选项进入例句 | `law` 的例句来自 `[A] ... [B] ... [C] ... [D] ...` |
| 完形说明进入例句 | `blank` 的例句来自 `For each numbered blank...` |
| PDF 粘连词进入词表 | `theanswersheet`、`blankandmarka` 等 |
| 释义混入例句 | `sheet: 纸张 一张纸`、`blank: 空白处 她翻开...` |

结论：污染不是前端展示问题，而是后端输入清洗和词库释义清洗不足。

## 修复内容

### 1. 过滤说明、题干、选项

修改文件：[section_splitter.py](/Users/mac/Desktop/Words/backend/section_splitter.py)

新增 `clean_exam_sentences()`，用于清洗已经分段后的真题内容。过滤范围包括：

- `Directions`
- `ANSWER SHEET`
- `Choose the best...`
- `Mark your answer...`
- `Read the following...`
- 写作/翻译说明
- 阅读题干
- `[A] [B] [C] [D]` 和 `［A］［B］［C］［D］` 形式选项
- 选项粘在文章末尾的情况

### 2. 确保所有入口都走清洗

修改文件：[main.py](/Users/mac/Desktop/Words/backend/main.py)

清洗现在覆盖两个入口：

- 启动时读取 `真题整理/`
- 用户上传 `.docx/.pdf`

这样不需要手动重新生成 `真题整理/`，服务启动时会自动过滤旧数据里的污染内容。

### 3. 索引构建前再次清洗

修改文件：[analyzer.py](/Users/mac/Desktop/Words/backend/analyzer.py)

在构建词频索引前再次调用 `clean_exam_sentences()`，作为后端兜底。还过滤了明显的 PDF 粘连词：

- 包含 `answersheet` 的 token
- 同时包含 `answer` 和 `sheet` 的 token
- 超长粘连 token
- `re/ve/ll` 等缩写碎片

### 4. 清理释义里的例句

修改文件：

- [analyzer.py](/Users/mac/Desktop/Words/backend/analyzer.py)
- [build_vocab.py](/Users/mac/Desktop/Words/scripts/build_vocab.py)

处理逻辑：

- 运行时加载墨墨词库时，清理 `meaning` 字段。
- 重新生成墨墨词库时，也在 `_clean_meaning()` 中清理。
- 对含中文的释义，只保留词性对应的中文意思，去掉后面的中英文例句片段。

### 5. 修复启动脚本

修改文件：[start.sh](/Users/mac/Desktop/Words/start.sh)

修复点：

- 优先使用 `python3.11` / `python3.10`，避免误用系统 `python3.9`。
- 依赖安装改为绑定到选中的 Python：`"$PYTHON" -m pip install ...`。
- NLTK 数据下载失败不再卡死启动。
- 前后端只监听本机：`127.0.0.1`，避免沙箱或系统权限对 `0.0.0.0` 的限制。

## 仍需注意

清除污染后，默认阈值下高频词数量会明显下降，甚至可能为 0。这是合理结果，因为原先的“高频”很大程度来自每年都重复出现的说明文字和答题卡文字。

后续建议重新定义频率口径，例如：

1. 按“年份”统计，而不是按 section。
2. 或降低默认高频/中频阈值。
3. 对阅读、完形、翻译、写作分题型分别统计。

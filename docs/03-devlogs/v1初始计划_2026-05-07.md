# v1 初始计划：以墨墨词库重构考研真题词频系统

## Context

**为什么做**：现有应用已能统计真题词频，但有三个核心缺陷：
1. **词汇基底不准**：用 `kaoyan_syllabus.txt`（5672词）作大纲白名单，范围远超墨墨权威分级；中文释义靠在线 API 拿英文定义，常常缺词。
2. **统计颗粒度太粗**：`paper_set` 以"文件名"为单位，同一年同一题型的多次出现没有去重；释义层无独立计数，无法回答"这个词的 v. 用法考过几次"。
3. **启动割裂**：要分别开两个终端跑后端和前端。

**目标**：用墨墨 PDF（402页，~7147词条）作为权威词汇基底（含中文释义、词性分组、考频分级），把统计颗粒度细化到 `(年份, 题型, 词性)` 三元组，实现"释义 + 次数 + 点击查例句"的交互；并提供一键启动脚本。

## 核心设计

### 1. 数据架构变化

**词汇基底**：从墨墨 PDF 一次性提取到 [墨墨单词本/](墨墨单词本/)：

```
墨墨单词本/
├── momo_vocab.json          # 总词库
├── 主词条.json              # 258 词群
├── 附录-基础词.json
├── 附录-低频大纲词.json
├── 附录-零频大纲词.json
└── 附录-低频超纲词.json
```

每个词条结构：
```json
{
  "lemma": "define",
  "group": "main",
  "group_idx": 1,
  "senses": [
    {"pos": "v", "meaning": "给…下定义，解释（词义）"},
    {"pos": "v", "meaning": "阐述，说明"}
  ]
}
```

5 个分组：
- `main` — 主词条（258 词群，必选基底）
- `basic` — 附录·基础词（~1819 词，可筛选）
- `low_syllabus` — 附录·低频大纲词（~753 词，可筛选）
- `zero_syllabus` — 附录·零频大纲词（~1648 词，可筛选）
- `low_extra` — 附录·低频超纲词（~469 词，可筛选）

**真题切片**：每篇试卷切分后落盘到 [真题整理/](真题整理/)，按"年份/题型"组织：

```
真题整理/
├── 2017/
│   ├── 01_完形填空.txt
│   ├── 02_阅读A.txt
│   ├── 03_阅读B.txt
│   ├── 04_阅读C_翻译.txt
│   ├── 05_写作A.txt
│   ├── 06_写作B.txt
│   └── meta.json
└── ...
```

题型枚举：`use_of_english` / `reading_a` / `reading_b` / `reading_c` / `writing_a` / `writing_b`

**统计单位**：去重单位由"文件名"改为 `(lemma, year, section, pos)` 四元组：

```python
word_index[lemma]["pos_units"] = {
  "v": {("2017","reading_a"), ("2018","translation"), ...},
  "n": {("2019","reading_b"), ...},
}
```

**词义计数规则**：同 POS 内所有释义共享同一计数与例句池（避免不可靠的词义消歧 WSD）。

### 2. 题型切分

考研英语真题结构：
```
Section I  Use of English          → use_of_english
Section II Reading Comprehension
   Part A → reading_a
   Part B → reading_b
   Part C → reading_c
Section III Writing
   Part A → writing_a
   Part B → writing_b
```

新建 [backend/section_splitter.py](backend/section_splitter.py)：用正则识别 Section/Part 锚点，切分原文为 sections。MVP 阶段只支持 16 个单年 PDF（2010-2025）。

### 3. POS 标注

用 NLTK `averaged_perceptron_tagger`，输出 Penn Treebank 标签（VB/NN/JJ/RB），映射到 `v/n/adj/adv` 4 类。WordNetLemmatizer 做词形还原。

### 4. 频率分级

`frequency = len(pos_units 并集) / 总 (year, section) 单位数`

阈值 `high_threshold=0.5` / `medium_threshold=0.2`，分级标签为单词级。

### 5. 筛选机制（两套叠加生效）

- **墨墨分组筛选**：勾选附录分组排除（`main` 主词条强制保留）
- **基础词过滤**：保留小学/中考/高考/四级 4 级过滤

`SYLLABUS_WORDS` 旧大纲白名单废弃，由墨墨 5 个分组并集替代。

### 6. 一键启动脚本

新建 [start.sh](start.sh)：自动检测依赖、下载 NLTK 数据、同时启动后端(:8000)和前端(:5173)。

## 设计决策（当时确定的）

1. **词性分桶颗粒度**：同 POS 释义共享计数（避免 WSD）
2. **老合订本（1986-2009）**：MVP 跳过，v2 再做
3. **POS 标注**：NLTK（轻量纯 Python），spaCy 作为可选升级
4. **在线词典回退**：墨墨没收的词仍调用 Free Dictionary API 兜底

### 修复 3 · 释义中剥离英文例句 → `scripts/build_vocab.py`

**根因**：`_clean_meaning` 在 english_ratio > 0.5 时跳过剥离；orphan sense 归属在跨页时可能错位。

**改法**：
1. **去掉比例阈值**：任何含中文的释义行，碰到 `\s+[A-Za-z]` 即截断
2. **更激进**：在 PDF 解析阶段就处理——释义行后紧跟的纯英文行视为例句，不合并到 meaning
3. 重跑 `scripts/build_vocab.py` 重新生成墨墨词库

**关键函数**：`_clean_meaning()`（`build_vocab.py` L306-321）

### 修复 6 · 常考例句指向最高频释义

**后端** [backend/main.py](backend/main.py) `_get_top_example`：
- 从 `senses` 中找到 count 最大的 sense（而非从 pos_counts 找 POS）
- 从该 sense 的 POS 桶中，取**最短的例句**（段落越短越可能是精准匹配）

```python
def _get_top_example(info):
    senses = info.get('senses', [])
    if not senses:
        return None
    best = max(senses, key=lambda s: s['count'])
    pos = best['pos']
    sents = info.get('sentences_by_pos', {}).get(pos, [])
    if not sents:
        return None
    # Pick shortest sentence (most precise match)
    return min(sents, key=lambda s: len(s['text']))
```

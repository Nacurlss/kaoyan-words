## 修改清单

### 1. 导入 1986-2009 合订本 → `scripts/build_papers.py` 扩展

**现状**：`build_papers.py` 只处理单年 PDF。需新增合订本 DOCX 处理路径。

**改法**：在 `build_papers.py` 中新增 `process_docx_bundle()` 函数：

1. 用 `python-docx` 读 DOCX，同时遍历 `doc.paragraphs` 和 `doc.tables`
2. **年份切分**：正则匹配 `(19|20)\d{2}年.*研究生入学` 识别年份边界
3. **Section 切分**：扩展 `section_splitter.py` 的匹配表，新增：
   - `Close Test` / `Cloze Test` → `use_of_english`
   - `Part I/II/III` + keyword（早期年份用 Part 而非 Section）
   - `Passage 1..5` → 阅读正文标记
   - Unicode 罗马数字 `ⅠⅡⅢⅣⅤ`
4. **题型容错**：早期年份（1986-1990）只有 完形+阅读+翻译 3 题型，无 Writing 和阅读 B/C
5. **表格提取**：DOCX 中的 table 内容（选项排版）需转换为文本行
6. 输出到 `真题整理/<year>/`，与现有结构一致

**关键文件**：
- [scripts/build_papers.py](scripts/build_papers.py) — 新增 DOCX 处理路径
- [backend/section_splitter.py](backend/section_splitter.py) — 扩展 section 匹配表

### 2. 修复文本段落丢失 → `backend/section_splitter.py`

**根因**：`_extract_sentences()` 用空行 `\n\n` 分割文本，然后 `\n`.join 合并段落，导致原始换行全部丢失。同时未修复 PDF 软换行（word-break across lines）。

**改法**：
- `_extract_sentences()` → 改为 **保留原文空白行结构**，不再合并行
- 新增 `_rejoin_hyphenated()` 函数：检测并修复 PDF 软换行造成的断词
  - 模式：`(\w+)-\n` 或 `(\w+)\n` 后接小写字母 → 合并
  - 例如：`air-\nports` → `airports`，`ai\nrp orts` → 不处理（太复杂）
- **翻译题标记**：在 extracted text 中，对 `(46)` `(47)` ... `(50)` 标记的句子用 `[[...]]` 包裹：
  - 正则 `\(4[6-9]|50\)` 识别翻译句起始，到下一编号或段尾结束
- **段落保留**：`Directions:` 后保留换行；`Text 1/2/3/4` 前保留空行；正文段落之间保留空行

**关键文件**：
- [backend/section_splitter.py](backend/section_splitter.py) — `_extract_sentences()` 改写

### 3. 隐藏 count=0 的释义 → 前后端同步

**前端**：无需改动（后端不发 0 值，前端自然不显示）

# 题型筛选功能设计方案

> 日期：2026-05-13  
> 版本：v2（融合缓存 + 前端同步建议）

## 1. 需求概述

在现有"整张试卷"词频统计基础上，增加按题型筛选能力。用户通过切换控件，只看某个题型中的词频数据。

## 2. 题型分组

| 选项 | 内容 | 对应 Section Key | 大致覆盖 |
|---|---|---|---|
| 全部题型 | 所有 section（当前行为） | `all` | 42 套 |
| 完形填空 | 完形填空 | `use_of_english` | 41 套 |
| 阅读理解 A+B | 阅读理解 A + 阅读理解 B（四篇） | `reading_a`, `reading_b` | 42 套 / 35 套 |
| 翻译题 | 阅读理解 C（翻译题） | `reading_c` | 37 套 |

> 注：不是每张试卷都有全部 section（如 reading_b 只有 35 套、reading_c 只有 37 套）。  
> **词频分母 = 当前题型实际覆盖的 section 数**，而非 42。

写作 A/B 不单独作为筛选项。

## 3. 方案：设置驱动 + 索引缓存 + 前端同步刷新

### 选型理由

- 复用现有 settings 系统，改动最小
- `_index_cache` 避免重复重建：同题型第二次切换零延迟
- 频率分母自洽：每个题型的总单元数独立计算
- 可选后台预热：启动后异步构建四份索引

### 数据流

```
用户切换题型
  → 前端: setSelectedWord(null) 关弹窗, setLoading(true)
  → 前端: await updateSettings({ section_filter: "reading" })
  → 后端: 更新 _session_settings["section_filter"]
  → 后端: _build_index() → 检查 _index_cache → 命中直接返回 / 未命中则构建
  → 前端: await fetchWords() / fetchPersonalWords()
  → 前端: setLoading(false)
```

## 4. 后端改动

### 4.1 `_session_settings` 新增字段

```python
_session_settings = {
    ...
    "section_filter": "all",
}
```

### 4.2 Section 映射表

```python
SECTION_FILTER_MAP = {
    "all": None,
    "cloze": ["use_of_english"],
    "reading": ["reading_a", "reading_b"],
    "translation": ["reading_c"],
}
```

### 4.3 索引缓存 `_index_cache`

```python
_index_cache: dict = {}
```

缓存 key 由以下字段组成：

```python
def _make_cache_key() -> tuple:
    settings = _session_settings
    return (
        settings.get("section_filter", "all"),
        tuple(sorted(settings.get("exclude_levels", []))),
        tuple(sorted(settings.get("exclude_groups", []))),
        tuple(sorted(p["filename"] for p in _session_papers if p.get("enabled", True))),
    )
```

### 4.4 `_build_index()` 改造

```python
def _build_index() -> dict:
    global _index_cache

    cache_key = _make_cache_key()
    if cache_key in _index_cache:
        return _index_cache[cache_key]

    active_papers = [p for p in _session_papers if p.get("enabled", True)]
    if not active_papers:
        return {}

    sf = _session_settings.get("section_filter", "all")
    allowed = SECTION_FILTER_MAP.get(sf)
    if allowed is not None:
        active_papers = [p for p in active_papers if p["section"] in allowed]

    word_index = analyzer.build_frequency_index(active_papers)

    # momo group filter
    exclude_groups = _session_settings.get("exclude_groups", [])
    if exclude_groups:
        excluded_lemmas = set()
        for g in exclude_groups:
            excluded_lemmas.update(MOMO_GROUPS.get(g, set()))
        word_index = {k: v for k, v in word_index.items() if k not in excluded_lemmas}

    exclude = _get_exclude_words(_session_settings.get("exclude_levels", []))
    if exclude:
        word_index = apply_basic_word_filter(word_index, exclude)

    word_index = annotate_word_index(word_index)

    _index_cache[cache_key] = word_index
    return word_index
```

### 4.5 缓存失效策略

| 触发事件 | 缓存处理 |
|---|---|
| 切换 `section_filter` | 命中同 key 则直接返回；未命中则构建 |
| 切换 `exclude_levels` / `exclude_groups` | 新 key，未命中时构建 |
| 上传/删除/启用试卷 | **清空 `_index_cache`** |
| 修改 `high_threshold` / `medium_threshold` | **不清缓存**（只影响分类，不影响索引） |

### 4.6 可选：启动后台预热

```python
@app.on_event("startup")
async def startup():
    # ... 现有逻辑 ...
    # 后台预热四份索引（可选，加速首次切换）
    import threading
    def warmup():
        for sf in ["all", "cloze", "reading", "translation"]:
            _session_settings["section_filter"] = sf
            _build_index()
        _session_settings["section_filter"] = "all"
    threading.Thread(target=warmup, daemon=True).start()
```

### 4.7 `/api/settings` 接口

- `GET /api/settings` — 返回中增加 `section_filter`
- `PUT /api/settings` — 接受 `section_filter` 字段；当 `section_filter` / `exclude_levels` / `exclude_groups` 变化时触发 `_build_index()`

无需新增 API 端点。

### 4.8 导出文件名加题型

```python
@app.get("/api/export/csv")
async def export_csv(band: str = Query("all"), ...):
    sf = _session_settings.get("section_filter", "all")
    sf_label = {"all": "all", "cloze": "cloze", "reading": "reading",
                "translation": "translation"}.get(sf, "all")
    filename = f"words_{sf_label}_{band}.csv"
    ...
```

## 5. 前端改动

### 5.1 `types.ts` — Settings 类型

```typescript
type SectionFilter = "all" | "cloze" | "reading" | "translation";

interface Settings {
  section_filter: SectionFilter;
  // ... 其他已有字段
}
```

### 5.2 `App.tsx` — 题型切换 UI

放在主内容区顶部、词频 band tab 同一行（不在 SettingsPanel 深处），因为这是核心浏览维度。

```tsx
const handleSectionFilterChange = async (value: SectionFilter) => {
  setLoading(true);
  setSelectedWord(null);   // 关闭当前详情弹窗，防止旧题型例句残留
  setPage(1);
  setPersonalPage(1);

  const next = await updateSettings({ section_filter: value });
  setSettings(next);

  if (band === "personal") {
    await fetchPersonalWords();
  } else {
    await fetchWords();
  }

  setLoading(false);
};
```

关键点：
1. **先 `await updateSettings()`**，再拉词表 — 保证后端索引已切换
2. **`setSelectedWord(null)`** — 防止弹窗显示旧题型例句
3. **生词本 tab 也要刷新** — `fetchPersonalWords()`

### 5.3 UI 文案

```tsx
<select value={sectionFilter} onChange={...}>
  <option value="all">全部题型</option>
  <option value="cloze">完形填空</option>
  <option value="reading">阅读理解 A+B</option>
  <option value="translation">翻译题</option>
</select>
```

并在旁边加小字提示：
> 词频按当前题型覆盖的 section 数计算

### 5.4 初始加载

页面初始化时从 `getSettings()` 读取 `section_filter`，默认 `"all"`。

## 6. 波及范围

| 组件/功能 | 影响 | 说明 |
|---|---|---|
| 词频列表 | ✅ 自动跟随 | 频率基于选中题型重算 |
| 单词详情弹窗 | ⚠️ 需主动关闭 | 切换题型时 `setSelectedWord(null)` |
| 释义次数 Popover | ✅ 自动跟随 | `sentences_by_pos` 已过滤 |
| 生词本 | ⚠️ 需主动刷新 | 切换题型时调用 `fetchPersonalWords()` |
| 导出 CSV/Excel | ✅ 文件名加题型 | `words_reading_high.xlsx` |
| 翻译缓存 | ✅ 不受影响 | 已全量缓存 |
| 预翻译 | ✅ 不受影响 | 不需要重新跑 |
| 试卷上传/管理 | ⚠️ 清缓存 | 上传/删除试卷清空 `_index_cache` |
| 词表排除设置 | ✅ 正交 | 不同 cache key，互不影响 |

## 7. 实施顺序

1. **后端**：`section_filter` + `SECTION_FILTER_MAP` + `_index_cache`
2. **后端**：`/api/settings` 适配，导出文件名加题型
3. **前端**：`types.ts` 加 `SectionFilter`，`App.tsx` 加分段按钮
4. **前端**：完善切换状态同步（关弹窗、刷新、loading）
5. **可选**：启动后台预热四份索引

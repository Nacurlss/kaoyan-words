# 翻译功能设计方案

> 版本: v0.3.0 候选特性
> 日期: 2026-05-12
> 状态: 设计完成，待实现

---

## 1. 需求概述

用户在使用「释义次数点击 → 弹出历年句子」功能时，希望：

1. **句子下方显示中文翻译**（灰色字体）
2. **目标词在译文中的对应含义加深颜色**
3. **不要逐句等待翻译**——预翻译全部句子，之后零延迟读取

---

## 2. 翻译引擎选择

| 引擎 | 选择 | 原因 |
|------|:---:|------|
| DeepSeek V4 Flash | ✅ | 翻译质量高、极便宜（¥1/百万tokens）、中文理解好 |

**API Key 存储**：`.env` 文件 `DEEPSEEK_API_KEY=sk-xxx`，加入 `.gitignore`。

**DeepSeek API 基础 URL**：`https://api.deepseek.com/v1/chat/completions`

---

## 3. 翻译流程

```
┌──────────────────────────────────────────────────────────┐
│  第0步：用户点击 「预翻译全部句子」                         │
│         └→ 后端扫描 _session_word_index 中所有            │
│            (sentence, target_word) 对                     │
│         └→ 按 3 次/秒 限速调 DeepSeek V4 Flash            │
│         └→ 存入 data/processed/translations/              │
│              └→ {hash前2位}/{md5}.json                    │
│         └→ 前端轮询进度：已翻译 3521 / 8000               │
│                                                          │
│  此后任何时间：                                           │
│         └→ 打开弹窗 → 判断无新试卷 → 读缓存 → 0 延迟      │
│         └→ 新上传试卷 → 点击该试卷句子时排队翻译            │
└──────────────────────────────────────────────────────────┘
```

### 3.1 缓存策略

- **key**：`md5(sentence_text + "|" + target_lemma)`
- **目录**：`data/processed/translations/ab/abcd1234....json`
- 同一句子加同一目标词无需重复翻译
- Rebuild 试卷后 hash 不变，缓存仍有效

### 3.2 限速策略

| 限额 | 值 | 说明 |
|------|:---:|------|
| 并发请求 | 1 | 顺序请求，避免触发限流 |
| 请求间隔 | 333ms | 3次/秒 |
| 批量大小 | 1句/次 | 便于缓存粒度、进度显示 |

## 4. 后端设计

### 4.1 新增文件

```
src/backend/translator.py          ← 核心翻译模块
data/processed/translations/       ← 翻译缓存目录
.env                               ← API Key（gitignore）
```

### 4.2 translator.py 结构

```python
class DeepSeekTranslator:
    def translate(sentence: str, target_word: str) -> TranslationResult
    def batch_translate(items: list[tuple[str, str]],
                        progress_callback) -> int
    def _cache_get(key: str) -> TranslationResult | None
    def _cache_put(key: str, result: TranslationResult)

class TranslationResult:
    original: str        # 原句
    translation: str     # 中文翻译
    highlight_start: int # 目标词在译文中的起始位置
    highlight_end: int   # 目标词在译文中的结束位置

# 全局状态
_translate_task: dict = {
    "running": False,
    "done": 0,
    "total": 0,
    "status": "idle",   # idle | running | done | error
}
```

### 4.3 Prompt 设计

```
You are a Chinese-English translator specialized in exam papers.
Translate the English sentence to natural Chinese.
Also identify which Chinese character(s) correspond to the word "{target_word}".
Return ONLY a JSON object (no markdown, no extra text):
{{"translation": "...", "highlight": [start_char_index, end_char_index]}}

Sentence: {sentence}
Target word: {target_word}
```

### 4.4 新增 API

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/translate/start` | POST | 触发后台批量预翻译任务 |
| `/api/translate/progress` | GET | 返回 `{done, total, status, current}` |
| `/api/translate/sentences` | POST | 传入 `[{text, word, lemma}]`，返回对应翻译列表 |

### 4.5 `/api/translate/start` 流程

```
1. 扫描 _session_word_index 所有 (sentence, word) 对
2. 去重，过滤已有缓存的
3. 设置 _translate_task = {running: True, total: N, done: 0}
4. 开启线程逐句调用 translate()
5. 每完成一句 _translate_task["done"] += 1
6. 完成后更新 status = "done"
```

### 4.6 `/api/translate/sentences` 流程

```
1. 接收 [{text, word, lemma}]
2. 对每个 item 计算 hash key
3. 查缓存 → 命中直接返回
4. 未命中 → 同步调用 API（单句，新试卷场景）
5. 写入缓存 → 返回
```

### 4.7 `.env` 配置

```
DEEPSEEK_API_KEY=sk-your-key-here
```

`main.py` 启动时用 `python-dotenv` 加载。

## 5. 前端设计

### 5.1 新增类型

```typescript
interface Translation {
  original: string;
  translation: string;
  highlight_start: number;
  highlight_end: number;
}

interface TranslateProgress {
  done: number;
  total: number;
  status: "idle" | "running" | "done" | "error";
  current: string;  // 当前正在翻译的句子片段
}
```

### 5.2 新增 API 调用

```typescript
// api.ts
fetchTranslations(items: {text: string, word: string, lemma: string}[]): Promise<Record<string, Translation>>
startPreTranslate(): Promise<void>
getTranslateProgress(): Promise<TranslateProgress>
```

### 5.3 UI 改动

| 位置 | 改动 |
|------|------|
| **App.tsx 顶部栏** | 新增「预翻译全部句子」按钮 + 进度条（仅当缓存未完成时显示）|
| **WordTable.tsx SenseDetailPopover** | 每句下方新增灰色翻译行 |
| **PersonalVocabTable.tsx SenseDetailPopover** | 同上 |
| **WordDetailModal.tsx** | 同上 |

### 5.4 翻译显示样式

```
┌──────────────────────────────────────────────────────┐
│ 英语一 · 2024 · 阅读理解A                             │
│ The government has proposed a new policy.            │
│                        ───────                       │  ← 目标词蓝色高亮
│ 政 府 提 出 了 一 项 新 的 政 策                     │  ← 灰色 #888
│     ──────                                           │  ← 对应译文加深 #555
└──────────────────────────────────────────────────────┘
```

### 5.5 弹窗加载流程

```
1. 打开弹窗 → 立即显示原文（已有缓存）
2. 调 /api/translate/sentences 批量查缓存
3. 有缓存 → 渲染翻译行（0延迟）
4. 无缓存（新试卷） → 显示「翻译中...」→ 后端同步返回 → 替换
```

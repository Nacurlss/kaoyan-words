# 通用项目目录骨架模板

> 适用于 AI coding 协作的个人项目。可迁移到新项目、兼容不同 AI 工具。

---

## 完整目录结构

```
my-project/
│
├── README.md                   ← 项目一句话介绍 + 5分钟快速启动
├── LICENSE                     ← 开源协议（可选）
├── .gitignore                  ← git 忽略规则
├── start.sh                    ← 一键启动入口
│
├── .ai/                        ← AI 工具配置（跨工具通用）
│   ├── rules.md                ←   项目规则（告诉 AI 怎么干活）
│   └── context.md              ←   项目背景（AI 快速了解项目）
│
├── src/                        ← 源代码
│   ├── backend/                ←   后端代码
│   ├── frontend/               ←   前端代码
│   └── shared/                 ←   前后端共享的类型/常量
│
├── scripts/                    ← 工具脚本（和 src 分开，不参与运行）
│   ├── build_data.py           ←   数据构建
│   ├── migrate_db.py           ←   数据库迁移
│   └── ...
│
├── data/                       ← 所有数据文件
│   ├── raw/                    ←   原始数据（不修改）
│   │   └── exam_papers/        ←     真题 PDF/DOCX
│   ├── processed/              ←   处理后数据
│   │   └── sections/           ←     切好的 TXT
│   └── exports/                ←   导出文件（CSV/Excel）
│       └── .gitkeep
│
├── tests/                      ← 测试代码
│   ├── unit/
│   └── integration/
│
├── docs/                       ← 所有文档（按生命周期编号）
│   │
│   ├── 01-requirements/        ← 阶段1：需求分析
│   │   ├── 问题定义.md          ←     核心问题 & 目标
│   │   └── 使用场景.md          ←     使用场景
│   │
│   ├── 02-design/              ← 阶段2：方案设计
│   │   ├── 架构设计.md          ←     架构设计
│   │   ├── 数据模型.md          ←     数据模型
│   │   └── 项目目录骨架模板.md  ←     本文件：目录骨架模板
│   │
│   ├── 03-devlogs/             ← 阶段3：开发日志
│   │   └── v1计划-2026-05-07.md    ←     每轮迭代一篇
│   │
│   ├── 04-issues/              ← 阶段4：问题跟踪
│   │   └── 问题清单.md             ←     Bug 清单
│   │
│   ├── 05-manual/              ← 阶段5：使用文档
│   │   └── 使用手册.md             ←     使用手册
│   │
│   └── 06-notes/               ← 阶段6：想法 & 学习笔记
│       ├── 灵感笔记.md            ←     灵感和待探索方向
│       └── 学习记录.md            ←     边做边学到的东西
│
└── .github/                    ← CI/CD（可选）
    └── workflows/
```

---

## 根目录原则

根目录文件数 ≤ 8 个，只放：

| 文件 | 职责 |
|------|------|
| `README.md` | 项目入口，5 分钟能看懂 |
| `.gitignore` | Git 忽略规则 |
| `start.sh` / `Makefile` | 一键启动 |
| `LICENSE` | 开源协议 |

---

## docs/ 按生命周期编号

| 目录 | 阶段 | 放什么 | 什么时候写 |
|------|------|--------|-----------|
| `01-requirements/` | 构思 | 问题定义、使用场景、MVP 清单 | 项目第一天 |
| `02-design/` | 设计 | 架构图、数据模型、技术选型 | MVP 编码前 |
| `03-devlogs/` | 构建 | 每次迭代的计划+复盘 | 每轮迭代后 |
| `04-issues/` | 修复 | Bug 清单、已知问题 | 发现问题就记 |
| `05-manual/` | 交付 | 使用手册 | 快做完时 |
| `06-notes/` | 运维 | 灵感、学习笔记 | 随时 |

---

## data/ 三区隔离

| 目录 | 属性 | 进 git？ |
|------|------|----------|
| `raw/` | 原始数据，只读不修改 | ✅ 进（如果不大） |
| `processed/` | 脚本生成，可重建 | ❌ 忽略 |
| `exports/` | 用户手动导出 | ❌ 忽略 |

---

## src/ vs scripts/

| | `src/` | `scripts/` |
|---|--------|------------|
| 谁跑 | 用户（通过 start.sh） | 开发者（手动） |
| 频率 | 每次启动 | 偶尔/一次 |
| 进包 | 进 | 不进 |

---

## .ai/ — 跨工具 AI 配置

```
.ai/
├── rules.md       ← AI 行为规则（回答模式、代码规范、文件路径约定）
└── context.md     ← 项目背景速览（技术栈、目录说明、当前进度）
```

命名 `.ai/` 而非 `CLAUDE.md`：不绑定具体工具，换 Copilot/Cursor/Aider 时只需复制内容。

---

## 文件命名规范

| 规则 | ✅ | ❌ |
|------|-----|-----|
| 文档名在前，日期在后 | `产品需求分析-2026-05-11.md` | `2026-05-11-产品需求分析.md` |
| 日期格式 `YYYY-MM-DD` | `v1计划-2026-05-07.md` | `5.11计划.md` |
| 版本 `v1` `v2` 放日期前 | `v1计划-2026-05-07.md` | `最终版.md` |
| 无版本时名称连写 | `导入与筛选改进设计-2026-04-27.md` | `导入筛选.md` |
| 目录名加数字前缀 | `01-requirements/` | `需求/` |

---

## 新项目快速创建

```bash
mkdir -p my-project/{.ai,src/{backend,frontend,shared},scripts,data/{raw,processed,exports},tests/{unit,integration},docs/{01-requirements,02-design,03-devlogs,04-issues,05-manual,06-notes}}
```

一条命令创建全部骨架。

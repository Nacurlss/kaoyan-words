## 二、智能筛选 + UI 重构

### 改动文件
- [backend/main.py](backend/main.py) — `_get_exclude_words` 函数（第 47-60 行）
- [frontend/src/components/SettingsPanel.tsx](frontend/src/components/SettingsPanel.tsx) — 整体重构

### 筛选逻辑：差集模式

每个等级筛去的是该等级的**独有词**（与更低等级的差集），而非全量：

| 等级 | 筛去的词 |
|------|----------|
| 小学词汇 | 小学大纲词（~464 词） |
| 中考词汇 | zhongkao 全部（~1055 词） |
| 高考词汇 | gaokao - zhongkao - primary（高考独有） |
| 四级词汇 | cet4 - gaokao - zhongkao - primary（四级独有） |
| 自定义词表 | custom.txt 内容 |

后端 `_get_exclude_words` 先加载所有词表，再按等级做差集运算。

### UI 结构

```
基础词过滤
├── ☑ 筛去基础词          ← 开关，一键勾选小学+中考
└── ▶ 高级设置           ← 可折叠，默认收起
    ├── ☑ 小学词汇        ← 默认勾选（与开关联动）
    ├── ☑ 中考词汇        ← 默认勾选（与开关联动）
    ├── ☐ 高考词汇        ← 默认不勾选
    ├── ☐ 四级词汇        ← 默认不勾选
    └── ☐ 自定义词表      ← 默认不勾选（如有 custom.txt）
```

- 「筛去基础词」开关：一键控制小学+中考
- 展开高级后，各方框独立生效
- 开关状态与高级方框联动

### 默认设置
- 默认 `exclude_levels: ["primary", "zhongkao"]`
- 后端 `_session_settings` 默认值同步修改

## 三、词形还原修复 + 碎词过滤

### 改动文件
- [backend/analyzer.py](backend/analyzer.py)

### 修改清单

1. **`er$` 规则**（第 50 行）：加词干长度 ≥ 3 限制
   - `(r"er$", "")` → `(r"([a-z]{3,})er$", r"\1")`
   - 效果：teacher→teach（保留），lawyer→lawyer（不再误还原为 law）

2. **`s$` 规则**（第 68 行）：加词干长度 ≥ 2 限制
   - `(r"s$", "")` → `(r"([a-z]{2,})s$", r"\1")`
   - 效果：cats→cat（保留），bus→bus（不再误还原为 bu）

3. **罗马数字过滤**：正则提取后过滤黑名单
   - `ii, iii, iv, vi, vii, viii, ix, xi, xii, xiii, xiv, xv, xvi, xvii, xviii, xix, xx`

4. **最小词长度**（第 234 行）：从 2 改为 3
   - `r"\b[a-zA-Z]{2,}\b"` → `r"\b[a-zA-Z]{3,}\b"`

5. **不规则映射补充**：审查现有 173 组映射，补充缺失的常见不规则变形

## 四、单词释义（联网 + 缓存）

### 改动文件
- [backend/dictionary.py](backend/dictionary.py) — 重构
- [backend/requirements.txt](backend/requirements.txt) — 加 `httpx`
- [backend/main.py](backend/main.py) — `GET /api/word/{lemma}` 改为异步查询

### API
Free Dictionary API：`https://api.dictionaryapi.dev/api/v2/entries/en/{word}`
- 免费、无需 API Key
- 返回词性、释义、例句

### 缓存策略
- 查询结果缓存到 `backend/wordlists/dict_cache.json`
- 先查缓存，缓存没有才请求 API
- 用户可删除缓存文件重置
- 5 秒超时，失败静默返回空列表

### 新增依赖
- `httpx` — 异步 HTTP 客户端

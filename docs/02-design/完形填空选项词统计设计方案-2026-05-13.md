# 完形填空选项词统计设计方案

> 日期：2026-05-13  
> 版本：v1

## 1. 需求

当前完形填空的 A/B/C/D 选项词在数据预处理时被 `clean_exam_sentences` 清洗掉了。用户希望在查看完形填空题型时，把选项词也纳入词频统计，了解真题考察过的词汇。

规则：
- **仅在选择"完形填空"题型时**选项词才生效
- 选项词和文章词合并统计，不区分来源
- 其他题型（全部 / 阅读理解 / 翻译）不受影响

## 2. 现状

原始数据文件 `data/raw/exam_papers/` 中有 44 个 DOCX/PDF，包含完整的完形选项（如 `21. [A] resolve [B] regret [C] retreat [D] retrieve`）。但在 `section_splitter` → `clean_exam_sentences` 阶段，选项被 `NUMBERED_OPTION_START_RE` 正则切掉了。

当前 section 文件示例：

```
data/processed/sections/2015_英语一/01_完形填空.txt
→ 只有文章原文，无选项词
```

## 3. 方案

### 3.1 整体流程

```
原始 DOCX/PDF (44个)
  → 提取脚本: 解析每个完形 section，提取选项词
  → 输出: 01_完形填空_options.txt（每行一个选项词）
  → 后端加载: _load_papers_from_disk() 读取 option_words
  → 构建索引: section_filter=="cloze" 时注入选项词到 sentences
  → 词频统计: 选项词和文章词统一计数
```

### 3.2 选项词提取脚本

完形选项格式（英语一为例）：

```
21. [A] resolve  [B] regret   [C] retreat  [D] retrieve
...
40. [A] partly [B] simply [C] similarly [D] generally
```

提取逻辑：
- 用 `split_pdf()` 或 `parse_file()` 拿到完形 section 的原始文本
- 正则匹配 `\d+\.?\s*\[[A-D]\]\s*(\w+)` 提取每个选项词
- 去重后写入 `_options.txt`

**输出文件**：`data/processed/sections/{year}_{type}/01_完形填空_options.txt`

```
resolve
regret
retreat
retrieve
partly
simply
...
```

### 3.3 后端加载

修改 `_load_papers_from_disk()`：

```python
# 在构建 paper dict 时
options_path = exam_dir / f"{sec['file'].replace('.txt', '_options.txt')}"
if options_path.exists():
    paper["option_words"] = options_path.read_text(encoding="utf-8").strip().split()
```

### 3.4 索引构建时注入

修改 `_build_index()`，在调用 `analyzer.build_frequency_index()` 前：

```python
sf = _session_settings.get("section_filter", "all")
if sf == "cloze":
    for p in active_papers:
        options = p.get("option_words", [])
        if options:
            p["sentences"] = p["sentences"] + options
```

选项词作为独立句子元素加入 tokenizer，和文章词统一处理。

### 3.5 缓存

`_make_cache_key()` 已包含 `section_filter`，完形填空题型的 key 和全部题型不同，命中逻辑自动隔离。

选项词文件生成后不再变化，不需要额外的缓存失效逻辑。

## 4. 波及范围

| 组件 | 影响 | 说明 |
|---|---|---|
| 全部题型 | ❌ 无 | options 不注入 |
| 阅读理解/翻译 | ❌ 无 | 同上 |
| 完形填空 | ✅ 词频增加 | 选项词合并入文章词统计 |
| 翻译缓存 | ❌ 无 | 选项词是孤词无句子翻译 |
| 已有数据 | ❌ 不修改 | 只新增 `_options.txt` |
| 前端 UI | ❌ 无需改 | 题型选择器已有 |

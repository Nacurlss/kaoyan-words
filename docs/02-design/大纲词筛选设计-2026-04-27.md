# 考研大纲词汇筛选 — 设计文档

## 概述

将筛选模式从"排除基础词"改为"仅显示考研大纲内单词"。从 GitHub 获取 2025 考研英语大纲词汇表（约 5500 词），作为包含过滤器，同时移除不再需要的基础词排除 UI。

## 一、大纲词表引入

**来源**：GitHub `busiyiworld/maimemo-export` → `2025考研英语大纲词汇5500.csv`

**处理**：
- 提取 CSV 第一列单词，去重转小写
- 保存为 `backend/wordlists/kaoyan_syllabus.txt`（每行一个单词）
- 启动时加载到 `SYLLABUS_WORDS: set[str]`

**文件**：
- 新增：`backend/wordlists/kaoyan_syllabus.txt`
- 修改：`backend/main.py`（加载逻辑）

## 二、后端筛选逻辑

**删除**：`_get_exclude_words` 函数（差集排除不再需要）

**新增**：启动时加载 `SYLLABUS_WORDS`

**修改 `_build_index`**：在 `annotate_word_index` 之后加包含过滤

```python
if SYLLABUS_WORDS:
    word_index = {
        lemma: info
        for lemma, info in word_index.items()
        if lemma in SYLLABUS_WORDS
    }
```

**简化 `_session_settings`**：去掉 `exclude_levels`，只保留阈值

**简化 `update_settings`**：只处理 `high_threshold` / `medium_threshold`

## 三、前端 UI 简化

**改动文件**：
- `frontend/src/components/SettingsPanel.tsx` — 删除基础词过滤区域，只保留频率滑块
- `frontend/src/App.tsx` — settings state 去掉 `exclude_levels`
- `frontend/src/types.ts` — Settings 接口去掉 `exclude_levels`
- `frontend/src/api.ts` — 同步类型

**UI 变化**：SettingsPanel 只保留「频率设置」区域（高频线/中频线滑块）

## 四、影响范围

| 文件 | 改动 |
|------|------|
| `backend/wordlists/kaoyan_syllabus.txt` | 新增 |
| `backend/main.py` | 删 `_get_exclude_words`，加大纲加载+包含过滤，简化 settings |
| `frontend/src/components/SettingsPanel.tsx` | 删基础词过滤区域 |
| `frontend/src/App.tsx` | settings 去 `exclude_levels` |
| `frontend/src/types.ts` | Settings 去 `exclude_levels` |
| `frontend/src/api.ts` | 类型同步 |

## 五、向后兼容

- 导出格式不变
- 频率阈值 API 不变
- 旧缓存文件 `dict_cache.json` 保留

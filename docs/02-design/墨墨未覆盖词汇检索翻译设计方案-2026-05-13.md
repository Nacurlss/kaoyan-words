# 墨墨未覆盖词汇检索与翻译设计方案

> 日期：2026-05-13  
> 版本：v1  
> 状态：已完成

## 1. 需求

检索所有在考研真题中出现、但墨墨词库中没有收录的单词，用 DeepSeek API 按考研大纲风格翻译释义（标注词性）。

排除规则：
- 非单词：人名、地名、品牌、公司名
- 碎片：词形还原器产物（`isn`, `aren`, `para` 等）
- 题目残留：数字、罗马数字、选项字母
- 缩写：`ceo`, `dna`, `ftc` 等

## 2. 方案

### 2.1 检索：API 分页 + 本地词库对比

```
后端 API (GET /api/words?band=all) 分页获取全部词形还原索引
  × 墨墨词库 (momo_vocab.json + 附录分组)
  × 基础词表 (小学/中考/高考/四级)
  × 系统词典 (/usr/share/dict/words, 235,976 词)
  × 人名/地名/碎片黑名单
  → 1975 个未覆盖实词
```

### 2.2 清洗：三级过滤

| 过滤层 | 方法 | 效果 |
|---|---|---|
| L1 已知词 | momo_vocab + 附录分组 + 词表 | 减去 7,123 |
| L2 黑名单 | 人名、地名、品牌、碎片 | 减去 ~500 |
| L3 系统词典 | macOS `/usr/share/dict/words` | 减去 ~492 |

### 2.3 翻译：DeepSeek API 批量

- BATCH_SIZE = 30，共 66 批
- Prompt 要求返回 JSON `{"word": "pos|释义"}`
- 词性简写：n/v/adj/adv/prep/conj/pron
- 释义 2-6 字，取考研核心义
- 缓存到 `data/processed/vocab_translations/`（按 batch key MD5）

## 3. 产出

| 文件 | 内容 |
|---|---|
| `data/exports/uncovered_words.json` | 原始未覆盖词 (2,967) |
| `data/exports/uncovered_words_final.json` | 精炼后 (1,975) |
| `data/exports/uncovered_words_translated.json` | 翻译结果 (1,975) |
| `data/processed/vocab_translations/` | 66 个翻译缓存 |
| `scripts/find_uncovered_words.py` | 检索脚本 |
| `scripts/deep_clean_uncovered.py` | 清洗脚本 |
| `scripts/translate_uncovered_words.py` | 翻译脚本 |

## 4. 验证

- 66/66 批全部成功，零 API 失败
- 翻译样例：`investigation→n|调查`、`shareholder→n|股东`、`recklessly→adv|鲁莽地`
- POS 分布：n=1073, adj=412, adv=283, v=204

> 最后更新: 2026-05-12 · v0.2.0

## 一、快速开始

### 1. 一键启动（推荐）

```bash
cd /Users/mac/Desktop/Words
./start.sh
```

浏览器打开 **http://localhost:5173**。

### 2. 手动启动

```bash
# 终端 1：启动后端
cd /Users/mac/Desktop/Words
uvicorn src.backend.main:app --host 0.0.0.0 --port 8000 --reload

# 终端 2：启动前端
cd src/frontend
npm run dev
```

### 3. 翻译功能前置配置（仅首次）

翻译功能依赖 DeepSeek API，需在项目根目录创建 `.env` 文件：

```
DEEPSEEK_API_KEY=sk-your-key-here
```

👉 去 [platform.deepseek.com](https://platform.deepseek.com) 登录 → API Keys → 创建 Key。

## 三、核心功能

### 3.1 查看单词频率

| Tab | 含义 |
|-----|------|
| **高频词** | 年频率 ≥ 高频线（默认 0.30，即约 30% 的年份出现过） |
| **中频词** | 中频线 ≤ 年频率 < 高频线 |
| **低频词** | 年频率 < 中频线 |
| **全部** | 所有词（含被排除但仍保留的） |
| **生词本** | 你上传的生词本（见 3.7） |

### 3.2 释义次数可点击

点击释义后面的 `(15)` 蓝色数字，弹出历年真题句子列表：

```
┌──────────────────────────────────────────────┐
│  law · n. · 42 个考试单元                   │
│                                              │
│  英语一 · 2004 · 阅读理解A                   │
│  The law requires all new buildings to ...   │
│  法 律 要 求 所 有 新 建 筑 物 ...            │  ← 灰色翻译
│                                              │
│  英语二 · 2018 · 完形填空                     │
│  ...                                         │
│  这 样 做 不 符 合 法 律 规 定               │
└──────────────────────────────────────────────┘
```

### 3.3 翻译功能

**工作流程：**

1. 首次使用时，顶部栏出现绿色 **「预翻译全部句子」** 按钮
2. 点击一次，后台开始批量翻译（约 39 分钟跑完 34,923 句）
3. 翻译期间正常使用其他功能
4. 跑完后，所有弹窗句子下方自动显示中文翻译
5. 翻译结果持久缓存到磁盘，**重启后无需重新翻译**

**翻译缓存位置：** `data/processed/translations/`（被 `.gitignore` 排除）

**翻译引擎：** DeepSeek V4 Flash（成本 < ¥3，翻译全部句子）

### 3.4 调整频率标准

在左侧「频率设置」区域拖动滑块：

- **高频线**（默认 0.30）
- **中频线**（默认 0.10）

年频率 = 该单词出现的年份数 / 总年份数（42 年）。例如：
- 0.192 = 在约 8 年的真题中出现过

### 3.5 查看单词详情

**点击单词表格中的任意一行**，弹出详情窗口，显示：

- 单词 + 词形变体
- 释义（按词性）+ 出现次数
- **真题例句（按词性分组）**：单词在原文中加粗高亮，标有 `英语一 · 2024 · 阅读理解A`，下方灰色中文翻译

### 3.6 搜索单词

搜索框输入关键词，按 Enter 搜索。支持：
- 单词本身（如 `economy`）
- 词形变体（如 `running` 也能通过词形还原找到 `run`）

### 3.7 生词本

**上传你的生词本：**

1. 点击顶部 **「上传生词本」** 按钮
2. 选择 `.xlsx` 或 `.txt` 文件
   - `.xlsx`：自动从所有单元格提取纯英文单词
   - `.txt`：每行一个单词
3. 系统自动词形还原 + 去重 + 匹配真题数据

**查看生词本：**

切换到 **「生词本」** Tab，每个生词显示：
- 单词 + 词频百分比
- 墨墨释义
- 最短真题例句（含出处 `英语一 · 2024 · 阅读理解A`）
- 未在真题出现的词灰色标记

**清除生词本：** 点击「清除生词本」按钮。

### 3.8 导出结果

点击「导出 Excel」或「导出 CSV」，导出当前 Tab 下全部数据。

### 3.9 导入新试卷

点击「导入试卷」或「导入文件夹」，支持 `.docx` / `.pdf` 格式。导入后词频统计自动重建。新试卷的句子会在点击时自动触发翻译排队。

## 四、设置说明

| 设置项 | 默认值 | 说明 |
|--------|:---:|------|
| 高频线 | 0.30 | 年频率 ≥ 此值为高频词 |
| 中频线 | 0.10 | 年频率 ≥ 此值为中频词 |
| 墨墨分组筛选 | 无 | 勾选的墨墨分组从词频中排除 |
| 常考例句来源 | 真题例句 | 勾选后显示墨墨原版例句 |
| 小学词汇 | 已排除 | 勾选后进一步滤除 |
| 中考词汇 | 已排除 | 勾选后进一步滤除 |
| 高考词汇 | 不排除 | 勾选后滤除 |
| 四级词汇 | 不排除 | 勾选后滤除 |
| 自定义词表 | 不排除 | 需在 `wordlists/custom.txt` 中维护 |

## 六、翻译功能 FAQ

### Q1：翻译要多久？
首次预翻译约 **39 分钟**（34,923 句，15 句/秒）。之后 0 延迟读缓存。

### Q2：重启后翻译还在吗？
在。缓存文件持久化到 `data/processed/translations/`。

### Q3：翻译质量如何？
DeepSeek V4 Flash，中英互译水平足以准确理解考研真题句子。

### Q4：翻译要花钱吗？
全部 34,923 句总成本 **< ¥3**（DeepSeek 按 token 计费，¥1/百万 tokens）。

### Q5：上传新试卷后翻译怎么办？
点击该新试卷的句子时，自动触发翻译 → 写入缓存。下次不需要重复翻译。

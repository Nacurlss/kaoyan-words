# 考研单词频率筛选应用 — 使用手册

## 一、快速开始

### 1. 一键启动（推荐）

打开终端，执行：

```bash
cd /Users/mac/Desktop/Words
./start.sh
```

脚本会自动检查依赖、下载 NLTK 数据，并同时启动后端（:8000）和前端（:5173）。浏览器打开 **http://localhost:5173** 即可使用。按 `Ctrl+C` 停止所有服务。

### 2. 手动启动

```bash
# 终端 1：启动后端
cd /Users/mac/Desktop/Words
python3 -m uvicorn backend.main:app --host 0.0.0.0 --port 8000

# 终端 2：启动前端
cd /Users/mac/Desktop/Words/frontend
npm run dev
```

### 3. 安装依赖（仅首次需要）

```bash
pip3 install fastapi uvicorn python-multipart python-docx pdfplumber openpyxl httpx nltk
cd frontend && npm install
```

## 三、操作指南

### 3.1 导入试卷

1. 点击顶部 **「导入试卷」** 按钮
2. 在文件选择窗口中，选中你的考研真题文件（支持 `.docx` 和 `.pdf` 格式）
3. 可以一次选中多个文件批量导入
4. 导入后，左侧试卷列表会显示所有已导入的试卷

> **提示**：应用启动时自动加载 1986-2024 共 47 年考研英语（一）真题（每年 3-6 个题型 Section）。如需添加新试卷，可使用「导入试卷」功能。

### 3.2 查看单词频率

导入试卷后，主区域会自动显示统计结果：

- **高频词**：篇均出现次数 ≥ 设定阈值（默认 0.5，即平均每两篇至少出现一次）
- **中频词**：篇均出现次数介于高、中频线之间
- **低频词**：篇均出现次数低于中频线

点击顶部分类标签（高频词/中频词/全部）切换查看。

### 3.3 调整频率标准

在左侧 **「频率设置」** 区域：

- 拖动 **高频线** 滑块：设定高频词的最低频率标准
- 拖动 **中频线** 滑块：设定中频词的最低频率标准

频率值 = 该单词出现的文章数 / 已导入文章总数。例如：
- 频率 1.0 = 每篇文章都出现
- 频率 0.5 = 平均每两篇出现一次
- 频率 0.2 = 平均每五篇出现一次

建议设置：
- 一轮复习：高频 ≥ 0.5，中频 ≥ 0.2（广撒网）
- 冲刺阶段：高频 ≥ 0.7，中频 ≥ 0.3（抓重点）

### 3.4 过滤基础词

在左侧 **「基础词过滤」** 区域：

- **中考词汇**（默认勾选）：排除约 1500 个初中基础词
- **高考词汇**（默认勾选）：排除约 2000 个高中基础词
- **四级词汇**（默认不勾选）：排除约 2500 个四级词汇

勾选/取消勾选后，结果即时更新。过滤掉的词不会出现在任何分类中。

### 3.5 查看单词详情

**点击单词表格中的任意一行**，弹出详情窗口，显示：

- 词形变体（如 `law, laws, lawful`）
- 释义（词性 + 中文意思）
- 真题例句——单词在原文中**加粗 + 下划线**标出，并标注试卷年份
- 出现次数和频率统计

### 3.6 搜索单词

在搜索框输入关键词，按回车键搜索。支持：
- 搜索单词本身（如 `economy`）
- 搜索词形变体（如 `running` 也能找到 `run`）

### 3.7 导出结果

点击顶部 **「导出 Excel」** 或 **「导出 CSV」**：

- **Excel**：格式化表格，含单词、次数、频率、释义、真题例句
- **CSV**：纯文本，适合进一步用其他工具处理

导出的是当前分类标签下的数据（如当前看"高频词"，则导出高频词数据）。

### 3.8 删除试卷

鼠标悬停在左侧试卷列表的任意试卷上，点击右侧出现的 **×** 按钮即可删除。删除后统计结果自动更新。

## 四、常见问题

### Q1：为什么有些单词的释义是空的？
当前版本释义功能基于内置词库（待完善）。后续版本将集成完整的英汉词典数据。

### Q2：为什么同一个单词的不同形式没有合并？
应用已内置词形还原功能，会将 `running/ran/runs` 归并为 `run`，但部分不规则变形可能未被覆盖。可以在单词详情的"词形变体"中查看。

### Q3：PDF 解析不准确怎么办？
应用使用 pdfplumber 提取文本，对标准排版的考试真题 PDF 效果较好。如果遇到扫描版 PDF（图片），文本提取准确率会降低，建议使用 docx 版本。

### Q4：如何添加自定义排除词表？
在 `src/backend/wordlists/` 目录下创建 `custom.txt`，每行一个单词，然后在页面左侧勾选「自定义词表」即可生效。

### Q5：数据存在哪里？
当前版本为会话级存储——刷新页面或重启服务后，数据会丢失，需要重新导入试卷。后续版本将支持持久化存储。

## 五、技术说明

| 项目 | 说明 |
|------|------|
| 后端框架 | Python FastAPI |
| 前端框架 | React + TypeScript + Vite |
